# Ziptrrip Todo Application

A full-stack Todo Application developed as part of the Ziptrrip technical challenge.

The application allows users to create, manage, search, filter, update, complete and delete tasks.

---

## Technologies Used

### Frontend

- React
- Vite
- Axios
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

---

# Features

- Create a todo
- View all todos
- View individual todo details
- Update todos
- Delete todos
- Mark todos as completed
- Search todos
- Filter by status
- Set priority
- Set due dates
- View task statistics
- Separate Todo Details page
- Query parameter based todo details page

For detailed functionality documentation, see:

[FEATURES.md](./FEATURES.md)
